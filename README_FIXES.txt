DAJU Gemini Fix (Code Fixes Only - Original Fonts & Assets Preserved)
===================================================================

Every original image asset, font definition (@font-face), font styling
(including the original Shrikhand sticker text-shadow), SVG watercolor,
and favicon has been preserved byte-for-byte from your original files.

IMPORTANT before previewing locally:
1. Copy your original `fonts/` folder (all .woff2 files) into this
   `DAJU Gemini Fix/` folder. Without `fonts/`, the browser falls back
   to system fonts (Georgia / system-ui).
2. Also copy `matcha-strawberry.jpg` and `og-image.png` from your
   original project folder if you have them locally.
3. Optional: update `SITE_URL` in `build.py` and the remaining prices /
   social handles in `CONFIG` at the top of `src/app.js`, then run:
       python3 build.py
